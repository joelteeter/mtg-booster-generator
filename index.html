Sharper text and edges, using an AI upscaler that runs on your graphics card in this browser (downloads ~3 MB once). Slow: about 10 seconds per card (≈2½ min per pack, ≈20 min for 8 packs), and PDFs get about 4× bigger. Best on photo paper, cardstock or a good laser printer.

CSVPDF frontsPDF backsMTGProxyPrinter

CSV: Scryfall format; MTGProxyPrinter's CSV import merges duplicate cards, so pack order is lost there. PDF fronts: 3×3 cards at 63×88 mm with cut lines; rounded corners are filled from the pixels next to them, the outer bleed stretches each card's edge pixels outward, and inverted-colour crosshairs mark every card corner for cutting. PDF backs: same pages as the fronts PDF with every position mirrored, so printing it on the back of the fronts puts each back behind its card. Use the same paper, bleed and "new page" settings for both. With "front only" double-faced cards, the cut lines are printed on the backs only. MTGProxyPrinter: a .mtgproxies document; open it with File → Open to print every card in pack order with your own MTGProxyPrinter settings (it follows the double-faced card setting too). The CSV lists each card once, as MTGProxyPrinter's import expects.

Images load from Scryfall's image server (cards.scryfall.io), one pack at a time; no extra API requests. Click a double-faced card to flip it.
